What gets harder without three.js

  • New shapes need their own geometry code. A knot, sphere, box or extruded letter is a short function; a detailed model file is not practical.
  • We own the plumbing: shader compile errors, losing the WebGL context, resizing. This page handles all three.
  • No helpers for clicking on objects in 3D. The hero does not need it.
